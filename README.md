# NIGHTSHIFT — JDM Performance + Audio (Vexo Digital concept)

A fictional, static e-commerce concept for portfolio demonstration. Includes responsive layouts, interactive product filters and search, cart, setup builder, make/model/year selector, and an original animated retro stereo display with dolphin, spectrum and voltage modes.

## Publish on GitHub Pages

1. Create a public GitHub repository named `nightshift-jdm-demo`.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root (not inside an extra folder).
3. Settings → Pages → Deploy from a branch → main → / (root) → Save.
4. Wait for deployment and visit `https://YOUR-USERNAME.github.io/nightshift-jdm-demo/`.

## Important

- No checkout, payments, customer orders, live stock, shipping or verified vehicle compatibility. Do not use this demo as a production store.
- Product names and prices are fictional illustrative examples; not verified HKS/BLITZ/Pioneer inventory or pricing.
- The dolphin animation is original SVG/CSS art inspired by early-2000s OEL stereos, not a copied Pioneer animation.
- The website uses external Unsplash photo URLs (real photography, not AI imagery). Internet access is needed for them to load. Photo licensing and suitability should be verified before any commercial use. Photos are not bundled into this ZIP because the build environment could not retrieve them. Product tiles use typographic graphics rather than fabricated product photos.
- To use client-supplied real photographs, replace the `.hero-photo` and `.culture-photo` background-image URLs in `styles.css`, and use appropriately licensed local product photos for real product listings.
- The Google Fonts CSS import requires an internet connection; system fallbacks are provided.
